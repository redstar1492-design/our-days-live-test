# v22 화면과 연결 구조

기준일: 2026-10-10. [명세](CURRENT_VERSION.md) · [검수](QA-v22.md)

## 기획 판단

이 구조는 적합합니다. 덤프 댓글은 특정 게시물에 관한 대화, 톡은 게시물 없이 시작하는 둘만의 대화, 사진은 기존 덤프를 자동으로 찾아보는 화면으로 역할을 나눕니다. 같은 내용을 별도의 모음에 다시 등록할 필요가 없고 북마크 상태도 원본 하나를 공유합니다. 하단 이름은 ‘1자’라는 설명보다 요구서의 구체 목록인 덤프·일정·톡·할 일·마이를 적용했습니다.

## 공통

하단 순서는 **덤프 / 일정 / 톡 / 할 일 / 마이**입니다. 버튼은 같은 너비이고 320px에서도 할 일은 한 줄입니다. 공통 dump 로고·DumpSans·입력·메뉴 구조를 유지합니다. 기존 작성자 필터와 저장 목록을 함께 적용합니다.

## 덤프와 장소

작성자/저장 필터 → 피드·사진 전환 → 원본 기록 구조입니다. 사진은 원본 media/photoUrl의 날짜별 3열 격자입니다. 클릭하면 사진·원문·댓글을 바로 열고 닫으면 사진 보기로 돌아갑니다. 텍스트 글에 빈 사진 칸을 만들지 않습니다.

작성창 장소 이름과 현재 위치는 선택 사항입니다. 현재 위치 버튼은 브라우저 권한/API를 요청하고 중복·게시를 막으며 완료·거부·시간 초과·지원 불가를 구분합니다.

장소 태그 → 지도 연결 모달 → Google Maps 링크 클릭 시 외부 지도입니다. 모달 안 지도 렌더링·장소 검색 목록은 없습니다. 댓글 지도 레이어는 초안을 보존하며 먼저 닫히고 기존 초점으로 복귀합니다.

## 일정과 여행

기존 달력·기간 바·같이하기를 유지합니다. 필터 메뉴의 여행 계획에서 기존 여행 목록·상세로 이동합니다. 달력에서 보기는 상세 모드를 해제하고 해당 날짜 달력으로 이동합니다. 일반 모음 관리/선택 UI를 제거하되 기존 데이터는 삭제하지 않습니다. 여행 대표 일정 시작일 선택은 유지하고 중복 + 버튼은 정리했습니다.

## 톡

상단의 톡 미리보기와 브라우저 저장/상대 미전송 안내를 표시합니다. 처음에는 비어 있습니다. 직접 입력·로컬 저장 또는 예시 대화 보기(선택) → 말풍선 목록·하단 입력창 구조이며 답장도 수동 예시입니다.

톡·댓글 입력은 공통 DumpSans 14px입니다. 목록 안 스크롤, 탭 왕복 초안, 저장 메시지 재접속 유지를 지원합니다. 메모리 초안은 새로고침 후 유지하지 않습니다. 실제 전송·상대 읽음·동기화·자동 수신·사진 첨부는 제공하지 않습니다.

## 할 일·마이·시작

할 일 D-day·정렬·편집·일정 연결과 마이 프로필·커버·계정·백업·초대 안내를 유지합니다. 소개 한 장 → 본인 정보 → 초대 미리보기 → 빈 앱과 실제 등록 안내입니다. 샘플 기록·상대 계정·톡 예시는 자동 주입하지 않습니다.

PC 1280×720, 모바일 크기 390×844·320×700에서 5개 탭·사진·지도 레이어·톡·여행 연결과 가로 넘침을 확인했습니다. 실제 모바일 기기·가상 키보드·스크린리더·위치 권한/수신 검수와 코드의 모의 Geolocation 검사는 구분합니다.

## 화면 배치 가이드

```text
덤프 피드 / 사진
┌─────────────────────────────────┐
│ dump                       작성 │  공통 헤더 56px
│ 전체 ⌄                   북마크 │  공통 필터 48px
│ 피드               사진         │  전환 행 44px
│                                 │
│ 피드: 원본 카드·본문·댓글        │
│ 사진: 날짜별 3열 격자            │  콘텐츠 스크롤
│       사진 → 원문·댓글 상세창    │
│                                 │
│ 덤프 | 일정 | 톡 | 할 일 | 마이  │  고정 하단
└─────────────────────────────────┘

톡
┌─────────────────────────────────┐
│ dump                       메뉴 │
│ 톡 미리보기 / 로컬 저장 안내    │
│ 상대 · 예시      예시 답장 받기 │
│              날짜               │
│ 상대 예시 말풍선                │
│                 내 입력 말풍선  │
│                                 │
│ 메시지 입력                전송 │  고정 입력
│ 덤프 | 일정 | 톡 | 할 일 | 마이  │  미확인 숫자
└─────────────────────────────────┘
```

## 컴포넌트와 데이터 연결

| 구성 | 책임 | 데이터/연결 |
|---|---|---|
| 공통 헤더·하단 내비게이션 | 동일한 로고·5개 탭·선택 상태 | 기존 페이지 전환, 톡 미확인 예시 숫자 |
| `filteredPostsV22()` | 작성자와 저장 조건을 동시에 적용 | 피드와 사진이 같은 원본 목록 사용 |
| `photoGroupsV22()` | 원본 모든 사진을 날짜별로 정리 | 원본 ID·사진 인덱스로 상세창 연결 |
| 원문·댓글 상세창 | 선택 사진·본문·댓글·댓글 입력 | 별도 게시물/사진 사본 생성 없음 |
| 장소 작성·지도 팝업 | 선택 입력·권한 상태·외부 지도 연결 | 원본의 장소 문자열·좌표, 댓글 초안 유지 |
| `chatPageV22()` | 빈 상태·말풍선·텍스트 입력·예시 메뉴 | `chatPreview.messages` 로컬 상태 |
| `chatUnreadV22()` | 미확인 예시 메시지 수 계산 | 하단 톡 뱃지, 99개 초과 `99+` |
| `chatRenderAfterV22()` | 렌더링 후 실제 화면 노출 확인 | 팝업/비활성 상태에서 임의 읽음 처리 방지 |

완성 예시 코드는 [단독 HTML](../dump-final.html), 분리 소스와 재빌드 안내는 [source/v22](../source/v22/BUILD.md)에 있습니다.
