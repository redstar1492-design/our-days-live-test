## 공통과 첫 시작

기존 덤프·일정·할 일·마이의 네 탭과 내장 DumpSans 글꼴·헤더·공통 입력창을 유지합니다. 첫 시작은 서비스 소개 한 장·자기 프로필·초대 미리보기·실제 빈 앱의 등록 안내로 구성합니다. 상대 이름을 대신 받거나 샘플 기록을 새 계정에 넣지 않습니다.

실제 덤프 게시·일정 저장·할 일 저장 성공 시 안내가 진행합니다. 안내 건너뛰기·중단·이어보기와 기존 데이터 보호는 유지합니다. 초대 링크는 표시용 미리보기이며 실제 계정 연결이나 기록 공유를 완료하지 않습니다.

## 덤프의 피드와 모음

덤프에 ‘피드 / 모음’을 제공합니다. 모음은 일반 모음 또는 여행으로 만들고 덤프·일정·할 일을 선택적으로 연결합니다. 기록 하나는 모음 하나에 연결할 수 있습니다. 모음 선택 없이 원래 방식으로 등록할 수 있습니다.

일반 모음 상세는 덤프·사진·일정·할 일 탭으로 구성합니다. 모음 안에서 새 기록을 만들거나 기존 항목을 검색해 가져옵니다. 다른 모음에 이미 연결된 항목과 여행의 대표 일정은 기존 항목 가져오기에서 무분별하게 중복 연결하지 않습니다.

모음에서 연 작성창은 선택한 모음을 기본값으로 표시합니다. 작성 중 모음을 바꾸거나 선택을 해제한 경우 저장 후 그 결과에 맞는 화면으로 돌아갑니다. 상세의 ‘모음 보기’로 연결된 모음에 복귀할 수 있습니다. 마이의 내 덤프·저장한 덤프·알림과 필터는 일반 피드로 정상 연결합니다.

모음을 삭제하면 연결만 해제하고 원본 덤프·일정·할 일·사진을 유지합니다. 원본 기록을 삭제하면 해당 모음에서도 그 기록이 사라집니다.

## 여행 계획

- 시작일과 종료일을 포함한 기간은 1~31일입니다.
- 여행 상세는 계획·할 일·덤프·사진 탭입니다.
- 여행 생성 시 전체 기간을 대표하는 달력 일정 하나를 자동 생성합니다.
- 여행 이름·기간과 대표 일정 이름·기간을 양방향으로 맞춥니다.
- 대표 일정 수정 시 여행 기간 제한과 기존 장소 날짜를 함께 검증합니다.
- 기간 밖에 장소가 남는 변경은 저장을 막고 장소 날짜를 먼저 수정하도록 안내합니다.
- 대표 일정이 삭제된 경우 여행 자체를 삭제하지 않으며 필요할 때 ‘달력에 추가’로 다시 연결합니다.
- 여행 날짜별 장소·선택 메모·선택 https 링크를 추가·수정·삭제합니다.
- 같은 날짜 안에서 위·아래 버튼으로 장소 순서를 바꿉니다.
- 장소를 추가할 때마다 별도 달력 일정을 자동 생성하지 않습니다.
- 링크가 없으면 장소 이름으로 지도 검색을 열며 이동 경로 계산·예약은 제공하지 않습니다.

## 사진

모음 사진 탭은 연결된 덤프의 사진 배열을 재사용합니다. 새로운 사진 사본이나 게시물을 만들지 않습니다. 사진 선택 시 크게 보고 원본 본문·댓글로 이어집니다. 불러오지 못한 사진은 오류 상태를 표시합니다.

## 저장·백업·검증

모음은 localStorage의 같은 앱 상태에 저장합니다. v20 기록에 모음 배열이 없으면 빈 목록으로 정규화하고 기존 기록을 유지합니다. 새 계정도 모음은 빈 목록입니다.

백업에서는 모음·여행·장소 ID와 연결, 제목·메모 길이, 날짜 범위·기간·https 링크·대표 일정 일치 여부를 검증합니다. 삭제된 모음을 가리키는 잘못된 연결은 허용하지 않습니다. 저장 공간 실패나 다른 창의 선행 저장 충돌이 있으면 전체 변경을 롤백합니다.

본앱·전달용 HTML·버전 보존본은 기존 앱 저장 키를 유지합니다. 체험 HTML은 **v20 체험 키를 그대로 유지**합니다. 같은 브라우저·같은 출처의 이전 체험 기록을 v21 업데이트로 지우거나 새 체험 공간으로 옮기지 않습니다. 파일 실행 주소와 웹 주소의 저장 공간은 서로 다릅니다.

## 서버와 실제 공유 범위

이번 모음·여행은 현재 브라우저에서만 작동합니다. 실제 상대 초대 수락·두 기기 공동 편집·동기화·실시간 채팅·푸시를 구현했다고 표시하지 않습니다. 기존 next-app 원본은 변경하지 않습니다.

[source/v21/backend/README.md](../source/v21/backend/README.md)에 기존 서버 사본·스키마/RLS 검토안·adapter 계약·읽기 전용 preflight와 정적 검사 결과를 보존합니다. SQL은 자동 적용 경로 밖의 검토 자료이며 실제 DB에서 실행하지 않았습니다. 이후 실제 인증·권한·트랜잭션·재시도·두 기기 검수가 필요합니다.
