# dump — 현재 버전 명세

버전: v20 · 기준일: 2026-10-09  
대상: `index.html` = 전달용 `dump-final.html` = `index0922testv20.html`  
이전 버전: [v19 HTML](../versions/v19/index.html) · [v19 검수](QA-v19.md)

## 처음 시작

1. ‘둘이 쓰는 덤프’에서 덤프·일정·할 일의 용도를 한 장으로 소개합니다.
2. 내 이름과 선택 사진을 설정합니다. 상대 이름이나 임의 상대 사진은 받지 않습니다.
3. 상대 초대 미리보기를 보여줍니다. 사용법 따라하기 또는 바로 시작을 선택합니다.
4. 사용법 따라하기를 선택하면 빈 실제 앱에서 덤프 → 일정 → 할 일 → 초대의 네 단계를 안내합니다.

v19의 소개용 사진, 가상 게시물·댓글·기간 일정·할 일 체험은 제거했습니다. 소개에 가짜 데이터를 넣지 않습니다. 새 설정은 입력한 자기 프로필과 첫 실행 완료 표식을 같은 상태에 저장하고, 덤프·일정·할 일·알림·관계 날짜를 비워 둡니다. 선택 사진은 압축 후 내 프로필에만 저장합니다.

내 이름은 앞뒤 공백을 제거한 1~20자입니다. 중복 저장을 막고 사진 처리 중 다음 이동을 제한합니다. 저장 공간 오류나 다른 창의 선행 저장이 발생하면 입력을 유지하고 기존 기록을 덮어쓰지 않습니다.

## 실제 앱 안 사용법

| 단계 | 안내 | 완료 기준 |
|---|---|---|
| 1 | 덤프 탭의 오른쪽 위 + → 실제 덤프 작성창 | 자기 새 덤프가 저장됨 |
| 2 | 일정 탭 → 오른쪽 위 + → 제목과 날짜 | 자기 새 일정이 저장됨 |
| 3 | 할 일 탭 → 오른쪽 위 + → 내용과 목표일 | 자기 새 할 일이 저장됨 |
| 4 | 마이 → 상대 초대 | 안내 마치기 선택 |

앱의 실제 버튼을 강조하고 해당 화면에서 무엇을 입력·저장하는지 설명합니다. 안내가 대신 등록하지 않습니다. 버튼을 눌러 창만 열거나 기존 내용을 수정한 것으로 다음 단계에 넘어가지 않습니다. 저장 실패 시에도 해당 단계에 머뭅니다.

각 단계는 건너뛸 수 있고 안내 전체를 중단할 수 있습니다. 안내 상태·단계·시작 시각(`startedAt`)을 브라우저에 저장합니다. 중단한 뒤 재접속하면 마이의 ‘사용법 이어보기’에서 이전 단계로 복귀합니다. 아직 시작하지 않은 가입 직후 상태와 중단 상태를 구분합니다. 실제 등록한 데이터는 안내를 마친 뒤에도 기록으로 남습니다. 마이의 ‘사용법 안내’에서 다시 따라할 수 있으며 재실행이 기존 기록 초기화를 뜻하지 않습니다. 안내는 실제 헤더의 + 버튼과 하단 탭을 강조하며 기존 기록의 수정창에는 신규 등록 안내를 붙이지 않습니다.

## 상대 초대와 연결 상태

**현재 서버가 없어 초대 화면·링크 미리보기만 제공합니다.** 실제 계정 인증, 초대 수락, 두 기기 연결·공유가 구현된 것으로 표시하지 않습니다.

- 초대 화면에서 링크 복사·공유를 사용할 수 있습니다.
- 링크에는 v20 표시 정보, 초대한 사람의 이름, 무작위 미리보기 식별자만 들어갑니다.
- 사진·게시물·관계 날짜·저장 기록은 링크에 넣지 않습니다.
- 받은 사람에게 초대한 이름을 표시하지만, 자기 이름은 수신자가 직접 설정합니다.
- 잘못되거나 크기가 과도한 초대 정보는 거부합니다. 이름을 HTML로 실행하지 않고 텍스트로 표시합니다.
- 복사 권한이 없으면 선택 가능한 링크를 보여주며 복사 성공으로 표시하지 않습니다.
- 공유 취소를 전송 성공으로 표시하지 않습니다.
- 초대 미리보기를 닫거나 다음으로 이동하면 표시용 이름 fragment를 URL에서 제거해 재접속 시 초대창이 반복되지 않게 합니다.
- 미리보기 동작으로 연결 상태·상대 프로필·알림·기록을 생성하지 않습니다.

새 프로필은 미연결 상태입니다. 필터는 전체와 자기 작성자만 제공하고, 상대 선택·함께 작성·다른 사용자로 전환·상대 알림은 노출하지 않습니다. 초대 화면은 마이에서 다시 열 수 있습니다.

이전 버전의 두 사람 시연 상태는 호환 경로로 보존합니다. 기존 준영·아정 식별자는 데이터 호환용이며, 시연 상태가 서버로 연결된 계정이라는 뜻은 아닙니다.

## 공통 화면과 저장

- 탭: 덤프·일정·할 일·마이.
- 공통 상단: `dump` 로고, 각 화면의 추가 또는 설정, 작성자 필터.
- 글꼴: 내장 Pretendard 기반 `DumpSans`. 입력창·버튼·내부 확인창에 같은 체계를 적용합니다.
- 긴 제목은 목록에서 말줄임하고 제목 클릭 시 상세로 이동합니다.
- 기록은 현재 브라우저의 localStorage에 저장하며 다른 기기와 자동 동기화하지 않습니다.
- 최신 `index.html`과 `versions/` 파일은 같은 앱 저장 키를 공유합니다. 체험 HTML만 `dump_onboarding_preview_v20_state`, `dump_onboarding_preview_v20_user`를 사용합니다.
- v20 체험 저장 공간은 본앱과 이전 v19 체험 공간을 변경하지 않습니다.
- 기존 기록이 있으면 첫 설정으로 강제 이동하거나 초기화하지 않습니다.
- 브라우저 QA 입력·개인 사진·스크린샷은 공개 저장소에 올리지 않습니다.

## 기존 앱 기능

덤프는 사진·글·선택 장소를 게시하고 같은 상세창에서 본문과 댓글을 봅니다. 반응·댓글 수·북마크·저장 취소를 제공합니다. 게시 완료 후 새 카드가 상단에 표시됩니다.

일정은 시작일·종료일로 하루 또는 여러 날을 등록합니다. 달력 막대는 날짜별 최대 세 줄이며 초과분을 숫자로 표시합니다. 목록은 사진·제목·메뉴로 간결하게 표시하고 제목을 누르면 기간·장소·메모를 확인합니다. 기존 두 사람 시연에서는 같이하기·취소와 겹친 사진을 유지합니다.

할 일은 완료 체크·작성자 사진·제목·D-day·목표일·메뉴의 한 줄 목록입니다. 가까운 기한을 우선하며 기한 지난 항목과 완료 항목은 아래로 보냅니다. 세부 단계와 직접 입력 분류를 지원합니다. 새 미연결 프로필은 자기 할 일로 등록합니다.

마이는 자기 프로필·커버 사진·계정 정보·내 덤프·저장한 덤프·사용법·상대 초대·데이터 설정으로 구성합니다. 연결된 상대를 임의로 만들어 보여주지 않습니다. 개인 기록 백업·복원을 제공합니다.

## 소스와 검수

[source/v20/](../source/v20/)에 실제 안내·초대 소스, 패치 helper, 재빌드와 검사 방법을 함께 보존합니다. 기준 앱은 기존 [v17 HTML](../versions/v17/index.html)이며 버전별 HTML과 검수 이력을 삭제하지 않습니다.

검수 수치·화면 확인·제한은 [v20 검수](QA-v20.md)를 따릅니다. 실제 서버 연결·푸시·네이티브 앱 출시까지 검증한 것으로 표현하지 않습니다.

- 1차: 실제 등록 흐름·취소·저장 성공 시 안내 진행을 확인하고, 시작 시각 보존과 중단 후 이어보기를 수정했습니다.
- 2차: 초대 수신 후 재접속·실제 버튼 강조·320px 입력창을 확인하고, 가입 직후 초대 화면 버튼 유지·URL fragment 정리·실제 + 버튼 선택자를 수정했습니다.

실제 서버 준비 계약은 [초대 서버 연결 문서](INVITATION_BACKEND.md)를 따릅니다. 미리보기 링크와 실제 서버 발급 토큰을 구분하며 설정 예시는 빈 값으로 보존합니다.
