## 화면과 덤프

하단은 덤프 / 일정 / 톡 / 할 일 / 마이입니다. 같은 글꼴·입력·메뉴·선택 상태와 5등분 버튼을 사용합니다.

피드·사진은 같은 원본 ID와 media/photoUrl을 사용합니다. 사진은 날짜별 3열이며 작성자·저장 조건을 교집합으로 적용합니다. 텍스트 글은 피드에만 남습니다. 사진 클릭 시 사진·원문·댓글이 바로 열리고 닫으면 사진 보기로 복귀합니다. 일반 모음 선택기는 숨기고 기존 collectionId는 보존합니다.

## 장소·현재 위치

장소 이름은 선택적 직접 입력입니다. 현재 위치 버튼은 보안 환경의 Geolocation API를 호출하고 브라우저 권한 결과를 기다립니다. 요청 중 중복 요청·게시를 막고 유효 좌표만 저장합니다. 제거·거부·시간 초과·늦은 응답을 구분합니다.

장소 태그는 지도 연결 모달과 Google Maps 검색 링크를 제공합니다. 좌표가 있으면 좌표, 없으면 장소 이름을 사용합니다. 사용자 클릭 이후 외부 지도로 이동합니다. 앱 안 POI 검색·검색 결과 API·내장 지도 렌더링은 없습니다. 댓글 지도 레이어를 닫아도 원문과 댓글 초안을 유지합니다.

## 톡 미리보기

텍스트만 지원하는 브라우저 로컬 미리보기이며 처음에는 비어 있습니다. 예시 대화·답장은 수동 선택으로만 추가합니다. 실제 상대에게 전송하지 않습니다.

저장 메시지는 재접속 후 유지하며 입력 초안은 탭 왕복 동안 메모리에 유지합니다. 새로고침 후 영구 초안은 아닙니다. 메시지 500개·본문 1,000자 한도와 IME·중복·저장 실패 처리를 포함합니다. 미확인 숫자는 실제 노출된 예시에만 적용하며 상대 읽음·알림이 아닙니다. 사진/영상 첨부·서버 대화는 없습니다.

## 일정·여행·할 일·마이

일정 기간 바·작성자 구분·같이하기/취소, 할 일 D-day·마감 정렬·하위 항목·일정 연결, 마이 프로필·커버·계정·백업·초대 안내를 유지합니다.

여행 계획은 일정 필터 메뉴에서 접근합니다. 여행 기간 1~31일·날짜별 장소·순서·대표 일정 하나와 제목/기간 동기화·연결 기록을 유지합니다. 일반 모음 관리 UI는 제거했지만 collections·장소·연결 ID는 백업에 보존합니다.
