GitHub Pages 공개 방법

🚀 3분 만에 무료 웹 앱 호스팅하기
  1. GitHub에 새 **Public Repository**를 만듭니다.
  2. 이 파일 전체를 **`index.html`** 이름으로 저장해 업로드합니다.
  3. 리포지토리 설정(**Settings**) 👉 **Pages** 메뉴로 이동합니다.
  4. Branch를 **`main`** 또는 **`master`**로 지정 후 **Save**를 누릅니다.
  5. 잠시 후 제공되는 URL (`https://사용자명.github.io/레포명`)로 연인과 함께 접속할 수 있습니다!
무가입 오프라인/동기화 지원

로컬 저장소(LocalStorage)가 기본 탑재되어 있어 별도 서버 없이도 내폰에서 즉시 모든 기록이 유지됩니다.
