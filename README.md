## 실행

`index.html`을 내려받아 브라우저에서 열거나 위 앱 링크로 접속합니다. 단독 HTML 버전은 별도 설치나 빌드가 필요하지 않습니다.

덤프, 일정, 할 일, 마이의 네 페이지를 제공합니다. 일정과 할 일은 한 줄 목록으로 표시하고, 제목을 누르면 상세 내용을 볼 수 있습니다. 설정에서 예시 계정 시점을 전환해 두 사람의 동작을 확인할 수 있습니다.

## 저장 방식

현재 `index.html`은 **브라우저 localStorage에 데이터를 저장하는 프로토타입**입니다. 실제 서버 로그인, 두 기기 간 계정 연결·동기화, 실제 푸시 알림은 이 HTML에 연결되어 있지 않습니다. 다른 브라우저나 주소에서 열면 저장 공간도 달라집니다.

사진과 작성 내용을 GitHub에 저장하는 구조는 아닙니다. 이 저장소에는 앱 코드와 명세만 관리합니다. 저장된 개인 데이터가 필요하면 앱의 데이터 설정에서 백업·복원을 사용합니다. 백업 파일은 개인 기록을 포함하므로 공개 저장소에 올리지 않습니다.

## 파일 관리

| 파일 | 역할 |
|---|---|
| `index.html` | 현재 단독 HTML 앱. GitHub Pages의 진입 파일 |
| `docs/CURRENT_VERSION.md` | 최신 화면 구성과 기능·데이터 기준 |
| `docs/QA-v17.md` | v17에서 수정·확인한 내용과 검수 한계 |
| `SPRINT_PLAN.md` | 현재 개발 상태, 아직 구현하지 않은 작업 |
| `next-app/` | 기존 Next.js·Supabase 전환 작업. 이번 v17 HTML 동기화에서 수정하지 않음 |

변경 시 HTML과 해당 명세를 같은 커밋에서 갱신합니다. 버전별 HTML은 Git 커밋 이력으로 추적합니다. `main`의 `index.html` 변경은 기존 GitHub Pages 배포 경로에도 반영됩니다.

## 첫 소개 화면

앱을 처음 열었을 때 나오는 시작 화면을 별도로 검토 중입니다. 현재 v17 본앱에는 아직 합치지 않았습니다. 시안 확정 후 첫 방문 표시와 다시 보기 동작을 포함해 구현합니다.

## 리소스와 검수

앱 내장 글꼴은 Pretendard 기반 `DumpSans`이며 관련 라이선스 표기를 HTML에 포함합니다. 예시 사진 등 일부 외부 리소스는 인터넷 연결에 영향을 받습니다.

v17 변경에 관련된 자동 검사 228개와 320px·390px 화면 검수 결과를 [검수 문서](docs/QA-v17.md)에 기록했습니다. 실제 휴대전화, 서버 인증·동기화, 푸시까지 검증한 제품 출시 인증을 의미하지 않습니다.
