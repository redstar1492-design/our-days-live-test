## 모음과 여행 계획

덤프의 ‘피드 / 모음’에서 여행이나 주제별 모음을 만듭니다. 덤프·일정·할 일을 모음 안에서 새로 등록하거나 기존 항목을 검색해 연결합니다. 모음은 선택 사항이며 일반 게시나 일정·할 일 등록에 필수로 요구하지 않습니다.

여행 모음은 1~31일의 기간을 정하고 날짜별 방문 장소·메모·링크와 순서를 관리합니다. 여행을 만들면 전체 기간을 나타내는 일정 하나가 달력에 연결됩니다. 여행 이름과 기간을 수정하면 그 일정도 맞추며 장소마다 별도 일정을 자동으로 만들지 않습니다.

사진 탭은 연결된 덤프의 원본 사진을 모아 봅니다. 사진 파일을 복제하거나 별도 사진 기록을 만들지 않습니다. 모음을 삭제해도 연결했던 덤프·일정·할 일은 남습니다.

## 처음 시작과 초대

서비스 소개 한 장 → 내 이름·선택 사진 → 상대 초대 미리보기 → 빈 앱의 실제 사용법 안내로 이어집니다. 상대 이름은 대신 입력하지 않습니다. 안내는 실제 덤프 게시·일정 등록·할 일 저장에 성공했을 때 다음 단계로 진행합니다. 등록한 내용은 자기 기록으로 남고 건너뛰기·중단·이어보기를 지원합니다.

**서버가 아직 없어 초대 링크는 화면 미리보기입니다.** 링크를 보내도 두 기기가 연결되거나 기록이 공유되지는 않습니다. 실제 상대 연결·동기화·실시간 채팅·푸시는 구현된 것으로 표시하지 않습니다.

## 실행과 저장

웹 주소로 접속하거나 `dump-final.html`을 내려받아 브라우저에서 엽니다. 별도 설치나 빌드가 필요하지 않습니다. 공통 글꼴과 로고는 HTML에 내장되어 있습니다.

기록은 현재 브라우저의 localStorage에 저장합니다. 같은 사이트의 본앱·전달용 HTML·버전 보존본은 본앱 저장 키를 공유합니다. `dump-onboarding-preview.html`은 본앱과 다른 **기존 v20 체험 저장 키를 유지**하므로 이전 체험 기록을 삭제하지 않습니다. 기존 사용자는 v21 업데이트 후에도 저장 기록으로 바로 들어가며 모음 목록만 빈 상태로 추가됩니다.

다른 브라우저·도메인·파일 실행 주소는 저장 공간이 다릅니다. 필요한 기록은 백업·복원으로 관리합니다. 사진과 개인 게시물을 GitHub에 저장하는 구조는 아닙니다.

## 파일 관리

| 경로 | 역할 |
|---|---|
| `index.html`, `dump-final.html` | 같은 최신 앱. 웹 진입 및 전달용 HTML |
| `versions/v21/index.html` | v21 보존본 |
| `versions/v20/index.html` 및 이전 버전 | 이전 기능·소개 흐름 이력 |
| `dump-onboarding-preview.html` | 기존 체험 기록을 유지하는 첫 시작 체험 |
| `docs/CURRENT_VERSION.md`, `SPRINT_PLAN.md` | 현재 명세와 개발 범위 |
| `docs/QA-v21.md` | 최종 코드 검사·화면 확인·한계 |
| `source/v21/` | 모음·여행 구현, 빌더·검사, 서버 준비 자료 |
| `source/v20/` | 이전 안내·초대 구현 보존 |
| `next-app/` | 기존 서버 앱 초안. 이번 버전에서 원본을 수정하지 않음 |

HTML과 문서·소스를 같은 커밋에서 관리합니다. 이전 버전·검수 문서는 보존하며 개인 브라우저 데이터·프로필 사진·QA 스크린샷은 업로드하지 않습니다.

## 서버 연결 준비

[source/v21/backend/README.md](source/v21/backend/README.md)에 기존 서버 초안 검토, 모음·여행 스키마 검토안, adapter 계약과 읽기 전용 사전 확인 SQL을 보존했습니다. 정적 준비 검사 결과는 실제 DB 적용이나 두 기기 검수 결과와 구분합니다. 실제 서버는 연결하지 않았으며 초안 SQL을 자동 migration 경로에 넣지 않습니다.
