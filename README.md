## 처음 시작

서비스 소개 한 장을 확인하고 **내 이름과 선택 사진만** 설정합니다. 상대방의 이름이나 사진을 대신 입력하지 않습니다. 프로필 설정 후 상대 초대 화면을 확인하고, 빈 앱에서 실제 등록 버튼을 따라 사용법을 익힙니다.

사용법 안내는 **덤프 게시 → 일정 등록 → 할 일 등록 → 상대 초대** 순서입니다. 앱의 실제 작성창을 열고 내용을 저장해야 다음 단계로 이동하며, 이때 등록한 내용은 자신의 기록으로 남습니다. 단계별 건너뛰기, 안내 중단과 다시 시작도 제공합니다. 샘플 피드나 가상 댓글을 실제 기록처럼 보여주지 않습니다.

안내 중단 후에는 마이의 ‘사용법 이어보기’에서 멈춘 단계로 돌아갑니다. 안내는 실제 + 버튼과 탭을 강조하며 초대 미리보기를 닫으면 이름을 담은 URL fragment를 제거합니다.

v19에서 사용했던 소개용 사진과 가상 피드·댓글·일정·할 일은 이번 시작 화면에서 제거했습니다. 이름 설정을 마친 새 사용자의 덤프·일정·할 일·알림에는 기본 예시 기록이 없습니다.

## 상대 초대의 현재 범위

**서버가 아직 없어 이번 버전은 초대 화면과 연결 준비까지 제공합니다.** 링크 복사·공유로 초대받는 화면을 확인할 수 있지만, 링크를 보내도 두 기기가 연결되거나 기록이 공유되지는 않습니다. 실제 연결 완료나 수락 완료로 표시하지 않습니다.

초대 링크에는 초대한 사람의 표시 이름과 미리보기 식별 정보만 들어갑니다. 게시물·사진·관계 날짜는 포함하지 않습니다. 받은 사람은 자신의 이름과 사진을 직접 설정합니다. 새 사용자의 화면에는 임의 상대 프로필, 사용자 전환, 상대방 알림을 만들지 않습니다.

기존 버전의 두 사람 시연 데이터는 호환성을 위해 보존합니다. 그 시연 동작은 실제 서버로 연결된 계정을 뜻하지 않습니다. 기존 데이터가 있는 사용자는 업데이트 후 바로 기존 기록으로 들어갑니다.

## 실행과 저장

위 링크로 접속하거나 HTML을 내려받아 브라우저에서 엽니다. 별도 설치나 빌드가 필요하지 않습니다. 내장 Pretendard 기반 `DumpSans`와 로고는 HTML 안에 포함합니다.

데이터는 **현재 브라우저의 localStorage**에 저장합니다. 서버 로그인·두 기기 동기화·실제 푸시는 연결하지 않았습니다. 브라우저, 도메인 또는 파일 실행 주소가 바뀌면 저장 공간도 달라집니다. 개인 기록을 GitHub에 업로드하는 구조가 아닙니다. 필요한 기록은 앱의 백업·복원 기능으로 관리합니다.

첫 실행 체험 파일은 v20 전용 저장 키를 사용해 본앱과 이전 v19 체험 기록을 건드리지 않습니다. 체험 파일도 한 번 설정하면 재접속 시 해당 기록으로 들어갑니다. 마이의 ‘사용법 안내’에서 안내를 다시 실행할 수 있습니다.
