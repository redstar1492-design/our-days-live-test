## 이번 버전

하단은 **덤프 / 일정 / 톡 / 할 일 / 마이**입니다. 덤프의 피드·사진 보기는 같은 원본을 사용합니다. 사진은 날짜별 3열 격자로 자동 표시하고 작성자·저장 필터를 함께 적용합니다. 사진을 누르면 사진·원문·댓글이 바로 열립니다.

덤프 작성에서 장소 이름을 직접 입력하거나 현재 위치를 선택할 수 있습니다. 현재 위치는 사용자가 버튼을 누른 뒤 브라우저 권한/API로 가져옵니다. 장소 태그는 지도 연결 모달을 열고 Google Maps 링크를 제공합니다. 앱 안 장소 검색 API와 내장 지도 렌더링은 없습니다.

톡은 **브라우저에만 저장하는 텍스트 미리보기**입니다. 처음에는 비어 있고 예시 대화도 선택해야 추가됩니다. 실제 상대 전송·상대 읽음·동기화·푸시는 제공하지 않습니다.

여행 계획은 일정에서 엽니다. 일반 모음 관리 UI는 제거했으며 기존 모음·여행·연결 ID는 삭제하지 않습니다. 일정·할 일·마이는 기존 기능을 유지합니다.

## 실행·저장·초대

웹 주소 또는 최종 HTML을 브라우저로 엽니다. 기록은 현재 브라우저 localStorage에 저장합니다. 본앱과 체험판 모두 기존 저장 키를 유지합니다. 파일·웹·다른 브라우저의 저장 공간은 다르므로 기록은 백업·복원으로 옮깁니다.

첫 시작은 서비스 소개 → 본인 프로필 → 초대 화면 미리보기 → 실제 등록 안내입니다. 새 계정은 빈 기록으로 시작하며 가짜 상대·자동 예시를 생성하지 않습니다. 상대 이름은 수신자가 직접 설정합니다.

서버가 없어 실제 계정 연결·초대 수락·공동 편집·두 기기 동기화는 제공하지 않습니다. [초대 서버 준비](docs/INVITATION_BACKEND.md)와 [기존 서버 검토 자료](source/v21/backend/README.md)는 보존합니다.
